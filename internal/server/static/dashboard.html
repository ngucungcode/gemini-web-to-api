Thêm / Cập Nhật Tài Khoản Cookie

Nhập Cookie chuỗi raw từ DevTools của gemini.google.com

Đặt tên ngắn gọn để phân biệt các tài khoản trong pool.

Mặc định là 0.

Chưa chọn file nào

Yêu cầu tối thiểu phải chứa __Secure-1PSID (hoặc đầy đủ chuỗi cookie từ batchexecute).

Cách lấy Cookie cực nhanh từ Trình duyệt:
  1. Mở gemini.google.com trên Chrome/Edge và đăng nhập.
  2. Bấm F12 → chuyển sang tab Network.
  3. Gửi bất kỳ câu hỏi nào trên Gemini, lọc từ khoá batchexecute.
  4. Bấm vào request batchexecute → Headers → sao chép toàn bộ giá trị tại Cookie: rồi dán vào đây.

Cấu Hình Admin Token

Nếu server chạy có cờ ADMIN_TOKEN, hãy nhập token vào đây để dashboard có thể quản lý, reload và thêm tài khoản.
